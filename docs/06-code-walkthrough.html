Config config.py:10

Frozen dataclass. Four settings only: days_history=30, buffer_min=15, timezone="Asia/Kolkata", fresh_hours=24. __post_init__ rejects zero or negative values. tz is a computed property that builds a ZoneInfo.

ReadSummary gate.py:66

What one history read tells the gate: latest, cadence, seen weekdays, the twice test, multi-daily, median runs. Built by _history_summary().

Dependency gate.py:85

One thing a view waits for, and its verdict: name, kind, ok, last_refresh, age_minutes, detail. No methods. The gate builds one of these for every outcome — measured, cycle, unreadable, function note.

ViewResult gate.py:99

One view's verdict: view, ready, dependencies. Method: blockers() returns the names of the dependencies that hold it up.

GateResult gate.py:112

The whole call's verdict: ready, views, fresh_hours, timezone. Methods: blockers() (flattened, no repeats), to_dict() (JSON-ready), render() (the report), __str__ (same as render).

Advice advice.py:45

The advisory result: view, safe_time, earlier_time, next_day flags, day counts, timezone, dependencies, unreadable, finished_by_day, warnings, text. Methods: render() returns the text, to_dict() is JSON-ready, __str__ prints the text.

DependencyRun advice.py:29

One upstream job for the advisory side: name, runs ("daily", "Mondays", ...), usual, latest, days, missed, note. Built by _to_advice() from a DependencyRow.

Commit models.py:10

One row of DESCRIBE HISTORY, or one MV refresh from the event log: version, timestamp, operation, params (the mode lives here), metrics. The classifier eats this.

Skipped models.py:21

A dependency that could not be resolved, and the reason. Never dropped silently — it travels to the report.

TableHistory models.py:36

What we learned about one gating table: finish_times (date → datetime), metrics_degraded, continuous, unknown_ops. Built by summarize().

GatingTable walker.py:53

A physical table that gates a view: name and kind. The walk returns these instead of bare names, so the gate knows how to check each one.

WalkResult walker.py:61

What one walk found: the gating tables, the blockers, and the notes. Built by walk().

DependencyRow recommend.py:22

Recommendation recommend.py:40

The pure-math result: safe, earlier, n_days, span_days, rows, all_clear, safe_next_day, earlier_next_day. Built by recommend(); consumed by report.py and advice.py.

6 · The classifier, live

history.py decides whether a commit counts as a refresh. Pick an operation and a mode. This tool runs the same rules as classify().

incremental

Why the mode matters

The commonest Delta operation is plain WRITE. Classify by name alone and most tables read as dormant — a confident wrong answer, not an error. That is why the rule reads both fields.

7 · The order to read the code

  1. models.py — the nouns. 45 lines. Learn Commit, Skipped, TableHistory.
  2. config.py — the four settings. 34 lines.
  3. history.py — the classifier. Pure, no I/O. Understand classify() and qualifying() first.
  4. client.py — the only I/O. Read the Workspace class and read_commits().
  5. walker.py — the dependency walk, the cycle guard, the depth cap.
  6. gate.py — the product. can_refresh() then _verdict_for(). Then the report.
  7. recommend.py — pure arithmetic for the advisory times.
  8. report.py — the advice text and its warnings.
  9. run.py and advice.py — the advisory pipeline, end to end.
  10. cli.py and obs.py — the edges: command line and logging.
  11. tests/ — the fake Workspace shows which calls the code makes.
The shape of the whole package

I/O lives in one class. All the thinking lives in pure functions. The report is generated from the result objects, never hand-written. The gate decides; it never writes.
